## 🎯 ASO最適化（App Store 検索対策）

App Store は **アプリ名 + サブタイトル + キーワード欄** の3つを検索インデックスに使う。
原則: ①3箇所で語を重複させない（重複は無駄）②キーワード欄はスペース不要・カンマ区切りで100字を使い切る
③単数形で登録すれば複数形も部分マッチ ④競合の少ない具体語（言語名・TOEIC等）を優先。

### アプリ名（30字）
```
ちりつも単語
```
（改名の狙いは"被り回避"。既存の Word Quest 系・単語系との差別化が最優先。"単語"は名前に含みつつ、独自の「ちりつも」で唯一無二にする）


**説明文(本文)**
単語アプリは、もう飽きた？
ちりつも単語は、相棒を育て、世界地図を旅し、仲間とボスに挑みながら単語を覚える——"学習まるごとゲーム"の単語アドベンチャーです。塵も積もれば、単語は力に。ただの4択で終わらせません。

■ 相棒と育つ（ペット育成）
学べば学ぶほど相棒が育ち、進化します。相棒はあなたの学習を後押しするボーナスにも。サボると元気をなくすので、毎日いっしょに続けましょう。あなただけの相棒が、学びの相棒になります。

■ 世界地図を旅する（冒険マップ）
「はじまりの草原」から「星の王座」まで、エリアを攻略しながら世界一を目指す旅。単語の習得度が、そのまま冒険の進み具合になります。地図が、あなたの成長を物語ります。

■ 仲間と協力（レイド）
みんなでボスに挑む協力イベント。正解でボスにダメージを与え、討伐すると限定称号を獲得。一人の勉強が、みんなの力になります。

■ 週替わりリーグ
同ランクの学習者とポイントを競い、上位は昇格・下位は降格。毎週リセットされるから、いつ始めても頂点を狙えます。

■ 苦手をその日のうちに復習
間違えた単語は自動で記録。ホームからワンタップで「苦手だけ」おさらいでき、記憶に定着します。間隔をあけて出し直す復習システムも搭載。

■ 10言語・29,000語をすべて検証
英・中・韓・西・仏・独・葡・露・ポーランド語、そして英語話者には日本語も。全ての単語を独立辞書と1語ずつ突き合わせて検証した、信頼できる訳で学べます。発音も聞けて、よく使う表現集も収録。

■ オフライン対応
インターネットがなくても学べます。

さあ、今日から単語で冒険へ。
