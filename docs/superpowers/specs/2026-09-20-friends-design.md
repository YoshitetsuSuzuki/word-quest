# ちりつも単語 フレンド機能 設計

## 目的
友達と一緒に**学習習慣を形成する**。競争そのものではなく「切らさない」「今日もう少しやる」
の二つの動機づけを作ることが狙い。

## 決定事項（2026-09-20 よしてつ様承認）
- 競う軸は **連続学習日数（ストリーク）** と **今週の学習語数** の2軸
- ランキングは**全言語合算の1本**（友達同士の比較が目的のため、言語別に割らない）
- **つつき（👋）** を入れる。1日1回・定型文のみ

### 軸の選定理由
- ストリーク: 後から始めた人でも毎日やれば追いつける。習慣形成に最も直結する
- 週間語数: 週ごとにリセットされ毎週仕切り直せる。その日の上積みを促す
- 正解率は採らない。簡単な問題ばかり解く人が有利になり、習慣形成と逆に働くため

## 再利用する既存資産
| 資産 | 用途 |
|---|---|
| `src/core/StreakEngine.ts` | 連続日数・最長記録・フリーズ（1日休んでも途切れない）。実装済み |
| `User.weekStart` / `weeklyPoints`（リーグ機能） | 月曜起点の週次リセット機構。同じ `weekStartOf()` を使う |
| ラッキーセブンの Supabase | PawPlanet が `paw_` で相乗り中。`wq_` 接頭辞で同居。追加費用ゼロ |

新規に必要なのは **今週の学習語数カウンタ** のみ。

## データモデル

### ローカル（`User` に追加）
```ts
/** 今週学習した語数（weekStart が変わるとリセット）。フレンドランキングの軸2 */
weeklyWords: number
```
`weekStart` は既存フィールドを共用する。リーグの週次精算と同じ契機でリセットされる。

### サーバー（Supabase・全て `wq_` 接頭辞）
- `wq_profiles` — user_id / display_name / friend_code / streak / weekly_words / week_start / category / updated_at
- `wq_friendships` — user_id / friend_id（双方向に2行）
- `wq_nudges` — from_id / to_id / nudge_day / claimed。`unique(from_id, to_id, nudge_day)` で1日1回
- RPC: `wq_friend_ranking` / `wq_lookup_by_code` / `wq_add_friend` / `wq_remove_friend` / `wq_send_nudge` / `wq_pending_nudges` / `wq_claim_nudges`

RLS は PawPlanet の `paw_` と同じ方針（匿名認証・自分の行のみ書込可・フレンドの行のみ読取可）。

## 画面（フレンドタブを1つ追加）

1. **今週のランキング** — 自分＋友達を合算1本。2軸をタブで切替
   - 🔥 連続日数 / 📚 今週の語数
   - 自分の行はハイライトし「あなた」バッジを付ける
2. **フレンド一覧** — 各行に `🔥12日 / 📚340語` と 👋 ボタン。
   **今日まだ学習していない友達に印**を出す（`last_study_date < today` で判定）
3. **あなたのコード** — タップでコピー。LINE等への招待（ShareLink 相当）

## つつき（👋）
- 1人につき1日1回。相手に「〇〇さんがつついています」と表示
- 受け取った側 **10コイン**、送った側 **5コイン**。双方に得があるので声を掛け合う動機になる
- フレンド同士のみ・1日1回・**文面は固定**（自由入力なし）

## 安全面（App Store 1.2 対策）
PawPlanet の審査で要求された項目を最初から入れる。
- 表示名の不適切語フィルタ（`SocialModeration` 相当）
- 通報導線（mailto）・非表示（ローカルの hidden Set）
- **自由入力は表示名のみ**。つつきは定型文に限定し UGC リスクを最小化

## 実装の段階
1. **ローカル**: `weeklyWords` カウンタ ＋ フレンド画面の UI（サーバー無しで動く形）
2. **サーバー**: `wq_` SQL とつなぎ込み（オプトイン方式。参加ボタンで初めて接続）
3. シミュレータ確認

## 非目標（今回やらない）
- 言語別ランキング（合算1本の方針）
- 自由入力のメッセージ交換（UGC リスク）
- 友達との同期対戦（既存の Battle と設計が衝突するため別途）
