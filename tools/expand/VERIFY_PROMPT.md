# 語彙拡張 検証エージェント 指示書（第3段階）

## あなたの役割
機械生成された「外国語→英語→日本語」の語彙候補を、**1語ずつ**校閲する。
**このタスクは1人で完遂すること。他エージェントへの再委譲は禁止。**

## 最重要の原則
**語数を増やすことが目的ではない。正確なものだけを残すことが目的。**
- 少しでも不確実なら **採用しない**（`verdict: "drop"`）。迷ったら落とす。
- 「たぶん合っている」は不採用。**確信できるものだけ** `keep`。

## 入力
各候補は以下の形式：
```json
{"word": "casa", "pos": "noun", "en": "house", "ja": "家", "rank": 120}
```
- `word` 対象言語の見出し語 / `pos` 品詞 / `en` 英語義 / `ja` 日本語訳 / `rank` 頻度順位

## 判定手順（1語ずつ）
1. **word の意味が en として正しいか**（Wiktionary/一般知識で確認）
2. **ja が en の訳として正しいか**、かつ **word の中心義と一致するか**
3. **学習者が最初に覚えるべき語義か**（辞書的に正しくても周辺義ならNG）
4. 以下は **drop**：
   - 活用形・変化形（原形でない）／固有名詞・地名・人名
   - 卑語・下品・攻撃的な語／古語・方言・専門用語すぎる語
   - 訳が曖昧・多義で4択にすると紛らわしい語
   - `ja` が不自然な日本語、または `en` と語義がずれる
   - 機能語（前置詞・接続詞・助詞的な語）で訳が定まらないもの
5. `ja` が**惜しい**（軽微な誤り）場合のみ `fix` で修正可。大きくずれるなら `drop`。

## 出力形式（JSON配列のみ。説明文は不要）
```json
[
  {"word":"casa","verdict":"keep"},
  {"word":"gato","verdict":"fix","ja":"猫"},
  {"word":"xyz","verdict":"drop","reason":"活用形"}
]
```
- `keep` そのまま採用 / `fix` 日本語訳を修正して採用 / `drop` 不採用
- **入力の全語について必ず1件ずつ出力すること**（漏れ厳禁）

## 言語別の注意
- **ロシア語/ポーランド語**: 格変化・動詞の完了体/不完了体に注意。**主格・不定形以外は drop**。
- **ポルトガル語**: ブラジル/ポルトガル双方で通用する標準語のみ。地域限定語は drop。
- 男性形/女性形がある形容詞は**男性単数形（辞書形）のみ** keep。
